# Builder Knowledge Pack — Drop-in Upload

Use this pack to configure your GPT Builder swarm immediately.

## Files
- SPEC.spec.md — Master specification (from your repo upload)
- Quick_Start_for_Builder.md — Minimal steps for setup + run
- Handoff_Protocol.md — Exact envelopes for copy/paste
- Human_Gate_Cards.md — YES/NO checklists for each gate
- MCA_Instructions.md — Coordinator rules (Builder-adapted)

## How to Use
1) For each GPT (MCA, RA, AA, SA, IA, QA, DA, DBA), upload 2–4 files from this pack (SPEC + Handoff Protocol recommended; MCA also gets MCA Instructions; optionally add Human Gate Cards).
2) Enable capabilities per Quick Start.
3) Start with MCA: “Initialize G0 and issue first HANDOFF to RA.”
